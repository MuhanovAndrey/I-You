# Руководство по тестированию

## Ручное тестирование

### Сценарий 1: Регистрация и вход

1. **Регистрация пользователя 1**
   - Откройте http://localhost:3000
   - Нажмите "Зарегистрироваться"
   - Email: `alice@example.com`
   - Username: `alice`
   - Пароль: `password123`
   - Telegram: `@alice_telegram` (опционально)
   - ✅ Успешная регистрация → перенаправление на `/pairing`

2. **Регистрация пользователя 2** (в режиме инкогнито)
   - Email: `bob@example.com`
   - Username: `bob`
   - Пароль: `password123`
   - Telegram: `@bob_telegram`
   - ✅ Успешная регистрация

3. **Тест входа**
   - Выйдите из аккаунта
   - Войдите с правильными данными
   - ✅ Успешный вход
   - Попробуйте неверный пароль
   - ✅ Ошибка "Invalid credentials"

### Сценарий 2: Связывание пары

1. **Отправка запроса (Alice)**
   - Введите в поиск: `bob`
   - ✅ Bob появляется в результатах
   - Нажмите "Отправить запрос"
   - ✅ Запрос отправлен
   - ✅ (Если настроен Telegram) Bob получает уведомление

2. **Принятие запроса (Bob)**
   - Войдите как Bob
   - ✅ Видите входящий запрос от Alice
   - Нажмите "Принять"
   - ✅ Оба перенаправлены на Dashboard
   - ✅ Видите "Вы и alice 💕"

3. **Тест отклонения**
   - Создайте третьего пользователя `charlie`
   - Отправьте запрос от Bob к Charlie
   - Charlie отклоняет
   - ✅ Статус запроса изменился

### Сценарий 3: Создание контента

1. **Причина любви (Alice)**
   - Нажмите "Причина любви"
   - Введите: "За твою искреннюю улыбку"
   - Создайте пост
   - ✅ Пост появился в ленте
   - ✅ Bob получил уведомление в Telegram

2. **Идея подарка (Bob)**
   - Нажмите "Идея подарка"
   - Название: "Букет роз"
   - Описание: "Красные розы, 25 штук"
   - ✅ Пост создан
   - ✅ Alice получила уведомление

3. **Пост о состоянии (Alice)**
   - Нажмите "Моё состояние"
   - Выберите "Эмоциональное"
   - Текст: "Сегодня очень счастлива!"
   - ✅ Пост создан

### Сценарий 4: Взаимодействие с постами

1. **Реакции**
   - Как Bob, откройте пост Alice
   - Нажмите ❤️
   - ✅ Реакция добавлена
   - ✅ Alice получила уведомление
   - Нажмите ❤️ снова
   - ✅ Реакция удалена

2. **Комментарии**
   - Нажмите "💬 Комментарии"
   - Введите: "Обожаю тебя!"
   - Отправьте
   - ✅ Комментарий добавлен
   - ✅ Alice получила уведомление

3. **Удаление**
   - Создайте тестовый пост
   - Нажмите 🗑️
   - Подтвердите удаление
   - ✅ Пост удален
   - Попробуйте удалить чужой пост
   - ✅ Кнопка недоступна

### Сценарий 5: Фильтрация и навигация

1. **Фильтры**
   - Переключайте между "Все", "Любовь", "Подарки", "Состояния"
   - ✅ Посты фильтруются правильно

2. **Выход**
   - Нажмите "Выйти"
   - ✅ Перенаправление на `/login`
   - ✅ Токен удален

## API тестирование с curl

### Регистрация
```bash
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "username": "testuser",
    "password": "password123"
  }'
```

### Вход
```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "password123"
  }'
```

### Создание поста (с токеном)
```bash
TOKEN="your-jwt-token-here"

curl -X POST http://localhost:5000/api/love-reasons \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "content": "За твою доброту"
  }'
```

### Получение постов
```bash
curl -X GET http://localhost:5000/api/love-reasons \
  -H "Authorization: Bearer $TOKEN"
```

## Тестирование Telegram

### Настройка тестового бота

1. Создайте тестового бота через @BotFather
2. Добавьте токен в `backend/.env`
3. Перезапустите backend

### Тест верификации

1. Зарегистрируйтесь с Telegram username
2. Найдите бота в Telegram
3. Отправьте `/start`
4. ✅ Получите подтверждение связи

### Тест уведомлений

1. Создайте пост от партнёра
2. ✅ Получите сообщение в Telegram
3. Проверьте все типы уведомлений:
   - Причина любви
   - Идея подарка
   - Пост о состоянии
   - Реакция
   - Комментарий
   - Запрос на связывание


### Проверка данных
1. Откройте Prisma Studio (http://localhost:5555)
2. Просмотрите таблицы User, LoveReason, etc.
3. ✅ Все связи настроены правильно
4. ✅ Каскадные удаления работают

### SQL запросы
```bash
psql $DATABASE_URL
```

```sql
-- Проверка пользователей
SELECT id, username, email, "pairedWithId" FROM "User";

-- Проверка постов с авторами
SELECT lr.id, lr.content, u.username 
FROM "LoveReason" lr 
JOIN "User" u ON lr."userId" = u.id;

-- Проверка реакций
SELECT r.type, u.username, lr.content 
FROM "Reaction" r 
JOIN "User" u ON r."userId" = u.id 
LEFT JOIN "LoveReason" lr ON r."loveReasonId" = lr.id;
```

## Тестирование безопасности

### Тест аутентификации
```bash
# Попытка доступа без токена
curl -X GET http://localhost:5000/api/love-reasons

# ✅ Должно вернуть 401 Unauthorized
```

### Тест валидации
```bash
# Короткий пароль
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "username": "test",
    "password": "12345"
  }'

# ✅ Должно вернуть ошибку валидации
```

### Тест CORS
```bash
# Из неразрешенного домена
curl -X POST http://localhost:5000/api/auth/login \
  -H "Origin: http://evil.com" \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"password123"}'

# ✅ Должно быть заблокировано CORS
```

## Известные ограничения

1. Пользователь может быть связан только с одним партнёром
2. Нельзя удалить чужие посты
3. Реакции ограничены предустановленными эмодзи
4. Telegram уведомления требуют верификации
5. Нет пагинации (все посты загружаются сразу)
