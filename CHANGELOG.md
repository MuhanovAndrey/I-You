# Changelog

Все значимые изменения в проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-17

### Добавлено

#### Backend
- ✨ REST API с 30+ endpoints
- ✨ Система аутентификации (JWT)
- ✨ Модели базы данных (8 моделей)
  - User (пользователь)
  - PairingRequest (запрос на связывание)
  - LoveReason (причина любви)
  - GiftIdea (идея подарка)
  - StatePost (пост о состоянии)
  - Reaction (реакция)
  - Comment (комментарий)
- ✨ Telegram бот интеграция
- ✨ Сервис уведомлений (7 типов)
- ✨ Валидация входных данных
- ✨ Middleware для аутентификации
- ✨ CORS защита
- ✨ Helmet.js для безопасности
- ✨ Хеширование паролей (bcrypt)

#### Frontend
- ✨ React приложение с TypeScript
- ✨ 4 основные страницы:
  - Login (вход)
  - Register (регистрация)
  - Pairing (связывание)
  - Dashboard (главная)
- ✨ 3 переиспользуемых компонента:
  - AnimatedBackground (анимированный фон)
  - PostCard (карточка поста)
  - CreatePostModal (модальное окно создания)
- ✨ State management (Zustand)
- ✨ Tailwind CSS стилизация
- ✨ Адаптивный дизайн (mobile-first)
- ✨ Анимация фона (сакура + сердечки)
- ✨ Glass-morphism эффекты

#### Функции
- ✨ Регистрация и вход пользователей
- ✨ Поиск пользователей
- ✨ Система связывания в пары
- ✨ Создание причин любви
- ✨ Создание идей подарков
- ✨ Создание постов о состоянии (физическое/эмоциональное)
- ✨ Реакции на посты (6 типов эмодзи)
- ✨ Комментарии к постам
- ✨ Удаление своих постов
- ✨ Фильтрация постов по типу
- ✨ Telegram уведомления о всех действиях

#### Безопасность
- 🔒 Хеширование паролей (bcrypt, 10 раундов)
- 🔒 JWT токены для аутентификации
- 🔒 CORS защита
- 🔒 Helmet.js для HTTP заголовков
- 🔒 Валидация всех входных данных
- 🔒 Защита от SQL инъекций (Prisma)
- 🔒 Защита от XSS

#### DevOps
- 🚀 Monorepo структура
- 🚀 TypeScript для backend и frontend
- 🚀 Prisma ORM для работы с БД
- 🚀 Vite для быстрой разработки
- 🚀 Hot reload для разработки
- 🚀 Environment variables
- 🚀 Руководства по деплою (4 варианта)

- Backend: Node.js 18, Express 4, TypeScript 5, Prisma 5
- Frontend: React 18, TypeScript 5, Vite 5, Tailwind CSS 3
- Database: PostgreSQL 14+
- Integration: Telegram Bot API

- Backend: 15 production + 13 dev dependencies
- Frontend: 7 production + 15 dev dependencies

### Известные проблемы

- Нет пагинации постов (все загружаются сразу)
- Нет восстановления пароля
- Нельзя изменить профиль после регистрации
- Нельзя разорвать пару через UI
- Нет удаления аккаунта через UI
- Telegram webhook только для продакшена (в dev - polling не реализован)
