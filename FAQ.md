# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое "ЯиТЫ"?

"ЯиТЫ" (I-You) - это веб-приложение для пар, где можно делиться причинами любви, идеями подарков и своим состоянием. Все действия сопровождаются уведомлениями в Telegram.

### Сколько это стоит?

Проект полностью бесплатный и открытый (MIT лицензия). Вы можете использовать и модифицировать его как угодно.

### Могу ли я использовать это для своих отношений?

Да! Вы можете:
1. Развернуть на бесплатном хостинге (Railway, Render)
2. Запустить локально на своем компьютере
3. Модифицировать под свои нужды

### Безопасно ли это?

Да. Приложение использует:
- Хеширование паролей (bcrypt)
- JWT токены для аутентификации
- HTTPS для продакшена
- Валидацию всех входных данных
- Защиту от SQL инъекций

### Какие данные хранятся?

- Email и пароль (хешированный)
- Имя пользователя
- Telegram username (опционально)
- Посты (причины любви, подарки, состояния)
- Реакции и комментарии

## Установка и настройка

### Какие требования для запуска?

- Node.js 18 или выше
- PostgreSQL 14 или выше
- npm или yarn
- (Опционально) Telegram бот токен

### Как быстро запустить локально?

```bash
git clone https://github.com/MuhanovAndrey/I-You.git
cd I-You
npm run install:all
cp backend/.env.example backend/.env
# Отредактируйте backend/.env
createdb i_you_db
cd backend && npx prisma migrate dev && cd ..
npm run dev
```

Подробнее в [GETTING_STARTED.md](GETTING_STARTED.md)

### Обязателен ли Telegram бот?

Нет. Приложение работает без Telegram, но тогда не будет уведомлений. Для полного функционала рекомендуется настроить бота.

### Как создать Telegram бота?

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `backend/.env`

Подробнее в [README.md](README.md#-настройка-telegram-бота)

### Что делать если порт 5000 или 3000 занят?

Измените в файлах:
- Backend: `backend/.env` → `PORT=5001`
- Frontend: `frontend/vite.config.ts` → `port: 3001`

## Использование

### Как связать аккаунты в пару?

1. Оба пользователя регистрируются
2. Один ищет второго по username
3. Отправляет запрос
4. Второй принимает запрос
5. Теперь вы пара!

### Могу ли я быть в паре с несколькими людьми?

Нет. В текущей версии один пользователь может быть связан только с одним партнёром.

### Как разорвать пару?

В текущей версии нужно сделать через базу данных. В будущем будет кнопка "Разорвать связь".

### Могу ли я удалить свой аккаунт?

В текущей версии - через базу данных. В будущем будет функция удаления аккаунта.

### Видит ли партнёр мои посты сразу?

Да, все посты отображаются в ленте обоих партнёров. Плюс партнёр получает уведомление в Telegram.

### Можно ли сделать приватный пост?

Нет, все посты видны партнёру. Это приложение для открытого общения в паре.

## Telegram

### Почему бот не отвечает на /start?

Проверьте:
1. Токен бота правильный в `.env`
2. Backend запущен
3. Username в профиле совпадает с Telegram username
4. Написали боту, а не другому пользователю

### Не приходят уведомления

1. Убедитесь что отправили `/start` боту
2. Проверьте что `telegramVerified: true` в базе данных
3. Проверьте что партнёр создаёт посты
4. Проверьте логи backend на ошибки

### Как настроить webhook для продакшена?

После деплоя backend:
```bash
curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook?url=<BACKEND_URL>/api/telegram/webhook"
```

Подробнее в [DEPLOYMENT.md](DEPLOYMENT.md)

## Ошибки

### "Cannot connect to database"

Проверьте:
1. PostgreSQL запущен: `sudo service postgresql status`
2. База данных создана: `createdb i_you_db`
3. `DATABASE_URL` правильный в `.env`

### "Port already in use"

Убейте процесс:
```bash
# Backend (порт 5000)
lsof -ti:5000 | xargs kill -9

# Frontend (порт 3000)
lsof -ti:3000 | xargs kill -9
```

### "Module not found"

Переустановите зависимости:
```bash
rm -rf node_modules package-lock.json
npm run install:all
```

### TypeScript ошибки

1. Проверьте версию Node.js: `node --version` (должна быть 18+)
2. Переустановите: `npm run install:all`
3. Очистите кеш: `npm cache clean --force`

### "Invalid token" при входе

1. Проверьте что `JWT_SECRET` одинаковый
2. Попробуйте выйти и войти снова
3. Очистите localStorage в браузере

## Безопасность

### Забыл пароль

В текущей версии нет восстановления пароля. Можно:
1. Сбросить через базу данных
2. Создать новый аккаунт

В будущем добавим восстановление через email.

### Как изменить пароль?

Сейчас - через базу данных. В будущем будет страница настроек.

### Безопасен ли мой пароль?

Да, пароли хешируются с помощью bcrypt (10 раундов) и никогда не хранятся в открытом виде.

### Могут ли другие видеть мои посты?

Нет, только ваш партнёр. Данные изолированы по парам.

## Кастомизация

### Можно ли изменить цвета?

Да! Отредактируйте `frontend/tailwind.config.js`:
```js
theme: {
  extend: {
    colors: {
      'sakura-pink': '#YOUR_COLOR',
      // ...
    }
  }
}
```

### Можно ли отключить анимацию?

Да, удалите или закомментируйте `<AnimatedBackground />` в `frontend/src/App.tsx`

### Можно ли добавить больше типов постов?

Да! Нужно:
1. Добавить модель в `backend/prisma/schema.prisma`
2. Создать controller и routes
3. Добавить UI в frontend

### Можно ли изменить лимиты?

Да, все лимиты можно настроить в коде. Например, количество реакций, длину постов и т.д.
